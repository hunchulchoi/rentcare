# 시연 절차 (PT 2026-12-03~04, RENTCARE-21)

시연 업체는 **제주 데모렌터카(테스트 업체)**. 차량 접수·상태 화면 맨 위에 "시연용: 테스트 업체로 접수됩니다.
실제 출동은 없습니다."가 보이고, 모든 접수·대여 등록은 `demo: true`로 저장된다(업체 화면 "데모" 배지).

## 전날

1. `scripts/e2e.sh` — 53/53 통과 확인 (로컬 서버 기준, 끝나면 배포 서버용 앱으로 다시 설치).
2. `scripts/demo-record.sh` — 백업 영상 `demo-out/demo-draft.mp4` 새로 만들기 (라이브가 막히면 이걸 튼다).
3. 백업 APK: 배포 서버가 죽었을 때 로컬 서버로 돌리는 앱
   `cd car && ./gradlew :app:assembleDebug -Prentcare.apiBaseUrl=<LOCAL_BASE_URL>` → 파일을 `demo-out/`에 복사.
4. 휴대폰: QR 읽기 확인, 화면 밝기 최대, 업체 화면을 띄울 노트북 브라우저에 `/vendor` 로그인.

## 시작 15분 전

```bash
scripts/demo-preflight.sh --reset   # 서버 깨우기 + 확인, 에뮬레이터 Park·SOC 60·경고등 끔, 앱 데이터 비움
```

`READY`가 나와야 한다. FAIL 줄마다 할 일이 적혀 있다. 서버는 1시간 요청이 없으면 멈추므로(Sablier),
시연 직전에 한 번 더 돌리거나 `/vendor` 화면을 새로고침해 둔다.

## 장면 순서 (약 7분)

| # | 화면 | 조작 | 말할 것 |
|---|---|---|---|
| 1 | 대여 정보 | "데모 EV 계약 불러오기" → 저장 | 계약 조건(대여 시 동일 잔량 80 %) 입력. 휴대폰 접수 코드·QR이 바로 나온다(사진 찍어 두기) |
| 2 | 반납 준비 | — | 현재 60 % < 계약 80 % → **반납 전 충전 필요**, 충전량 kWh. 값은 실제 SDK |
| 3 | 반납 준비 | `scripts/vconsole.sh soc 100` → 새로고침 | 잔량 변화가 바로 반영, 내비 도착 예상 99 % → **반납 기준 충족** |
| 4 | 대여 정보 → 반납 준비 | 반납 조건 "추가 충전 면제" → 저장 | 계약마다 판단이 달라진다 |
| 5 | 반납 준비 (휘발유) | "데모 휘발유 계약 불러오기", "모의 60%" / "모의 95%" | **모의 값임을 말한다**: 에뮬레이터에 연료 API가 없어 화면에 "시연용 모의 값" 표시 |
| 6 | 고장·사고 접수 | `scripts/vconsole.sh soc 60`, `scripts/vconsole.sh telltale TPMS On` → 접수 화면 | 켜진 경고등이 접수에 자동 포함, 바퀴 위치는 모른다고 표시(추측 안 함) |
| 7 | 고장·사고 접수 | (선택) "지도에서 위치 고르기" → 동의 → 접수 보내기 | 접수번호 즉시 발급. 안 되면 "미접수"와 재전송(중복 없음) |
| 8 | 노트북 `/vendor` | 목록 → 상세 → "확인" → 조치 "견인, 40분" → "조치완료" | 업체는 한국어로 본다. 차량 화면 단계가 접수 → 확인 → 조치중(예상 시각) → 완료로 바뀐다 |
| 9 | 휴대폰 | QR → 6자리 첨부 코드 → 사진 | 코드는 QR에 없다(보안). 업체 상세에 사진이 붙는다 |
| 10 | 휴대폰 `/r` | 대여 때 찍어 둔 8자리 코드 → 시동 불가 → 동의 | 차 화면을 못 쓸 때도 접수. 업체 목록에 "휴대폰 접수" |
| 11 | 대여 정보 | "반납 완료" | 차량 데이터 삭제, 첨부 코드·휴대폰 접수 코드 즉시 무효 |

영어 장면을 넣으려면 1번에서 언어 "English" — 차량·휴대폰은 영어, 업체는 한국어(유형 "시동 불가", 메모 원문).

## 복구

1. **서버가 답하지 않음** (`/api/health` 실패): 90초 기다렸다 preflight 다시. 그래도 안 되면 Portainer 스택
   `rentcare` 재시작. 시간이 없으면 로컬 서버(`scripts/server.sh start`, `tailscale funnel --bg 3000`)와 전날 만든
   백업 APK(`adb install -r demo-out/<백업>.apk`)로 전환. 업체 화면도 LOCAL_BASE_URL로 연다.
2. **에뮬레이터가 죽음** (macOS Metal 드라이버): Android Studio 도구 창 밖에서 다시 시작하거나
   `emulator -avd Pleos_Connect_2_1_0_API_34 -no-snapshot-load`. AVD는 `swiftshader_indirect`. 2분 이상 걸리면 백업 영상.
3. **에뮬레이터 인터넷 없음**: 에뮬레이터 재시작. **비행기 모드 토글 금지** (복구 안 됨).
4. **Virtual Console 명령이 안 먹음**: `scripts/vconsole.sh state` → 실패면 에뮬레이터 재시작.
5. **반납 준비가 "정보 부족"**: 내비 도착 예상이 현재 잔량보다 높으면 쓰지 않는다(정상 동작). SOC를 100으로 올리거나
   그대로 "추측하지 않는다"를 설명.
6. **QR이 안 읽힘**: 화면의 주소를 휴대폰에 직접 입력 (`…/m?lang=ko`, `…/r?lang=ko`).
7. **접수가 안 감**: 화면에 "미접수 · 다시 보내기"가 뜬다. 서버 복구 후 다시 보내기 — 같은 접수 1건만 생긴다(시연 포인트로 써도 됨).
8. **모두 실패**: `demo-out/demo-draft.mp4` 재생.

## 끝난 뒤

- 시연 접수는 `demo: true`, 90일 후 자동 삭제. 바로 지우려면 업체 화면에서 정리(아직 삭제 기능 없음 — 기간 만료로 삭제).
